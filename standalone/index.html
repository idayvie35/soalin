Koneksi Live Google Apps Script & AI Studio

Langkah Setup Cepat GAS + AI Studio:
  1. Salin semua file .gs dari menu Kode GAS & Blogger ke proyek Google Apps Script Anda.
  2. Di Apps Script, buka Project Settings → Script Properties lalu tambahkan properti GEMINI_API_KEY (API Key dari Google AI Studio).
  3. Klik Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone), lalu tempel URL .../exec di atas.
